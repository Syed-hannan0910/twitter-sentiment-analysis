🔬 How It Works

TweetSense uses NLTK's VADER (Valence Aware Dictionary and sEntiment Reasoner) — an NLP model purpose-built for social media text.

  • Understands emojis, slang & abbreviations
  • Handles CAPS emphasis (GREAT vs great)
  • Reads punctuation weight (great!!! vs great)
  • Degree modifiers (very good, kind of bad)
from nltk.sentiment.vader import SentimentIntensityAnalyzer

sia = SentimentIntensityAnalyzer()
scores = sia.polarity_scores("I love this! 😍")
# → {neg:0.0, neu:0.294, pos:0.706, compound:0.6249}

📐 Score Interpretation

Positive compound ≥ +0.05
Negative compound ≤ −0.05
Neutral −0.05 < compound < +0.05

The compound score normalises all VADER signals into a single value between −1 (most negative) and +1 (most positive).
